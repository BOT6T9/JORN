# SereneNotes Journal (Pure HTML, Python Flask & JSON)

A minimal, calming personal journal built with:
- **Python Flask** (`app.py`): Backend API routes, persistent JSON file storage, and mood reflection endpoint.
- **HTML & Vanilla JavaScript** (`templates/index.html`): Responsive journal canvas with typography controls, paper styling, auto-save, and mood trends.
- **JSON** (`data/diary_store.json`): File-based JSON database for journals and diary entries.

---

## Getting Started

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the App
```bash
python app.py
```

### 3. Open in Browser
Visit [http://127.0.0.1:5000](http://127.0.0.1:5000) to start writing and reflecting.
